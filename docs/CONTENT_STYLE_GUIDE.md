# Content style guide

- **Voice:** plain, direct, kind. Write for a busy seller on a phone, possibly reading in a second language.
- **Claims:** only what the code does. "Photos stay on your device" is true for both tools. Never say "guaranteed acceptance"; say "meets the rules we can measure".
- **Sources:** marketplace rules always show their source and "last checked" date; mark unverified rules "Unverified".
- **Numbers:** Indian grouping (1,000; 1,00,000), ₹ before amounts, "px", "KB", "MB".
- **Status words:** Pass / Check / Fail (product photos); Done / Done · note / Failed (converter). Always with text, never colour alone.
- **Errors:** what happened + what to do. "Couldn't read this image. It may be damaged, or not really a JPG, PNG or WebP."
- **Punctuation:** curly apostrophes and quotes in UI text; sentence case for headings and buttons.
- **Avoid:** hype ("revolutionary", "AI-powered"), fake urgency, unexplained jargon, invented statistics or testimonials.
